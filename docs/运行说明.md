# AI 记忆卡 · 运行说明（Day 7 MVP）

> 适用：Windows 本机，不依赖 Docker。
> 目标：把「网页版 MVP」从零跑起来，浏览器里能打开、能读写记忆。
> 最后验证：2026-09-21，两条命令均实测可起、`/api/v1/health` 返回 200。

---

## 一、这套 MVP 由哪几部分组成

| 层 | 是什么 | 端口 | 技术 |
|---|---|---|---|
| 网页 | 根目录 `index.html`（单文件，零依赖） | 5500 | HTML/CSS/JS |
| 静态服务器 | `python -m http.server` 把网页发出来 | 5500 | Python 标准库 |
| 服务端 | `server/` 里的 FastAPI 应用 | 8000 | FastAPI + SQLAlchemy |
| 数据库 | 开发期 `server/dev.db`（SQLite） | — | 免装 |

网页通过 `fetch` 调 `http://127.0.0.1:8000/api/v1` 拿数据，跨端口由服务端 CORS 放行。

---

## 二、起服务端（后端，先起这个）

```powershell
cd D:\AI-sound-card\server

# 首次：建虚拟环境 + 装依赖 + 建表（只做一次，之后跳过）
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m alembic upgrade head

# 每次起服务
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

验证后端起来了：浏览器开 `http://127.0.0.1:8000/api/v1/health`，看到 `{"status":"ok"}` 即可。
接口文档在 `http://127.0.0.1:8000/docs`。

> 说明：开发期不配 `.env` 也行，默认用 SQLite（`sqlite:///./dev.db`），数据落在 `server/dev.db`。

---

## 三、起网页（前端）

**另开一个终端**，在仓库根目录：

```powershell
cd D:\AI-sound-card
python -m http.server 5500
```

然后浏览器打开：

```
http://localhost:5500/
```

（`http://127.0.0.1:5500/` 也可以。）

---

## 四、怎么停

在两个终端分别按 `Ctrl + C` 即可。先后端、后网页，或任意顺序都行。

---

## 五、常见坑

1. **页面打开但全是示例数据 / 控制台报「后端未连接」**
   → 后端没起或端口不对。先确认 8000 的 health 是不是 `{"status":"ok"}`，再看网页。
   → 起服务端时命令里的 `cd D:\AI-sound-card\server` 不能省，否则 `app.main` 找不到。

2. **浏览器报 CORS 错误（跨域）**
   → 服务端已配好 CORS，允许 `localhost:5500` / `127.0.0.1:5500`。
   → 如果你改端口访问（比如 `:8080`），需要同步改 `server/app/core/config.py` 的 `cors_origins` 并重启后端。

3. **换浏览器/无痕窗口后账号变了**
   → 网页用「随机演示账号 + localStorage」静默登录，凭据只存本机、不进代码。
   → 新无痕窗口会注册一个新 demo 账号，属预期，演示无影响。

4. **端口被占用**（`address already in use`）
   → PowerShell 查占用：`Get-NetTCPConnection -LocalPort 8000`，再 `Stop-Process -Id <PID>` 释放。

## 六、前端调的后端接口（一览）

| 用途 | 方法 | 路径 |
|---|---|---|
| 登录（静默） | POST | `/api/v1/auth/login` |
| 注册（首次兜底） | POST | `/api/v1/auth/register` |
| 拉记忆列表 | GET | `/api/v1/memories?limit=50` |
| 写/覆盖一条记忆（幂等） | PUT | `/api/v1/memories/{id}` |
