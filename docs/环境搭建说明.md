> 原则：所有 SDK 装 **D 盘**，不占 C 盘空间
> 最后验证：2026-09-17，`flutter doctor` Android toolchain 全绿

## 三、镜像选择（国内必需）

| 用途 | 镜像 | 备注 |
|---|---|---|
| Flutter SDK 下载 | `https://storage.flutter-io.cn` | 实测 2.05 MB/s，**必须带 User-Agent 头**，否则 403 |
| pub 包 | `https://pub.flutter-io.cn` | 首次 `pub get` 较慢（本人实测 20+ 分钟），属带宽问题，不是卡死 |

## 四、跑起来（真机调试）

```powershell
# 1. 开一个新终端
cd D:\AI-sound-card\app

# 2. 拉依赖（首次很慢，之后秒过）
flutter pub get

# 3. 手机插 USB，打开「开发者选项 → USB 调试」，确认能被识别
flutter devices

# 4. 跑
flutter run
```

> 本项目是**录音类 App，必须用真机**。模拟器没有真实麦克风输入，
> 录音链路（`record` 插件 → WAV PCM16）测不了。
> 另外真机请把手机系统时间/时区设对，否则录音文件时间戳会错。

### 常用调试命令

```powershell
flutter doctor -v            # 查环境
flutter analyze              # 静态检查
flutter test                 # 跑单元测试
flutter build apk --debug    # 单独验构建链路
flutter clean                # 构建缓存出问题时清一下
```

## 五、常见坑

1. **`flutter doctor` 报 Visual Studio 未安装** —— 只影响 Windows 桌面 target，**跑安卓完全不需要**，忽略。
2. **许可协议没接受** —— `sdkmanager --licenses` 成功标志是输出 `All SDK package licenses accepted`，且 `licenses/` 下出现 7 个文件。
3. **`pub get` 卡很久** —— 看 `%LOCALAPPDATA%\Pub\Cache\hosted\pub.flutter-io.cn` 里的包数量是否在涨；在涨就是没卡死。
4. **adb 认不到手机** —— 先装手机厂商 USB 驱动，或跑 `adb kill-server && adb start-server` 重启 adb 服务。
